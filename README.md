# Kali Sales Performance Dashboard

### A data driven view of Kali's sales performance, customers, products and sales team.

## Overview

The Kali Sales Performance Dashboard was created in Power BI to turn business data into clear and meaningful insights.

The dashboard brings together sales, customer, product and salesperson information to give Kali a better understanding of its overall sales performance and the factors contributing to it.

## What the Dashboard Shows

* Overall sales and revenue performance
* Sales trends over time
* High value orders and their contribution to revenue
* Customer purchasing activity
* Product performance
* Salesperson performance
* Key trends and business insights

## Data & Analysis

The project uses an Excel dataset containing Kali's customer, sales, product and salesperson information.

The data was prepared and analysed in Power BI using:

**Data Cleaning → Data Transformation → Data Modelling → DAX Calculations → Data Visualisation**

## Tools Used

* Microsoft Excel
* Microsoft Power BI
* DAX
* Data Modelling
* Data Analysis
* Data Visualisation

## Business Questions

The dashboard was designed to help answer important questions about Kali's business, including:

* How is Kali's sales performance changing over time?
* Which products are generating the most revenue?
* Which salespeople are performing best?
* How much revenue is generated from high value orders?
* What customer trends can be identified?
* Where are the strongest areas of sales performance?

## Project Objective

The objective of this project was to transform Kali's raw business data into an interactive Power BI dashboard that makes sales performance easier to understand and supports data driven decision making.
